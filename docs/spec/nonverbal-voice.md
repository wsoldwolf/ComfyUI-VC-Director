# 非言語発声の自動計画

Buildのscenarioモードで、指定台詞を保持したまま息遣い・反応声を計画する。最終音声はH3が生成する。声の種類と時刻を指定しても、音質や再現を保証しない。実H3での比較検証は未実施。

## 入力

作品又は展開の`発声`に`指定台詞と非言語発声`を指定する。台詞なしで声だけを許可する場合は`非言語発声のみ`を使う。既存の`なし`と`指定台詞のみ`は引き続き追加の声を禁止する。パターンの選択だけでは発声を許可しない。

```markdown
# 発声パターン natural
* 許可: 軽い息遣い、溜め息、息を呑む、小さな笑い声
* 頻度: 控えめ
* 強さ: 弱め

# 作品
* id: example
* 発声: 指定台詞と非言語発声
* 発声パターン: natural
```

`# 発声パターン ID`は一意な英小文字・数字・アンダースコアのIDを持つ共通定義。`許可`は必須。`頻度`は`控えめ / 動作に合わせる / 多め`、`強さ`は`弱め / 中程度 / 強め`。既定は控えめ・弱め。任意の`指示`に声の選び方を記述できる。定義の位置は前方・後方参照に対応する。

作品の設定を展開が継承する。展開の`発声パターン`で設定を切り替え、次のfieldで個別に上書きできる。同一ブロックではfieldの順序によらずパターン適用後に上書きする。展開での禁止は`発声: なし`、台詞だけへ戻す場合は`発声: 指定台詞のみ`を使う。

```markdown
* 非言語発声: 息を呑む、溜め息
* 発声頻度: 控えめ
* 発声強度: 弱め
* 発声指示: @heroは驚いた瞬間に息を呑む。台詞の後で小さく息を吐く。
```

パターンなしで上記fieldを直接指定してもよい。許可リストは選択できる声の上限であり、全種類を使う義務ではない。頻度は場面に応じたLLMの計画指示であり、毎秒の回数を強制する値ではない。発声指示は種類の選択・人物・配置を計画するために使う。登録外の声や新しい言葉を許可するものではない。`「あっ」`や`「うん」`などの言葉を出す場合は作者の台詞として指定する。

| 許可に記述する声 | Scene eventのtext |
|---|---|
| 軽い息遣い | breath |
| 荒い息遣い | pant |
| 溜め息 | sigh |
| 息を呑む | gasp |
| 小さな笑い声 | chuckle |
| 笑い声 | laugh |
| 力む声 | effort |
| 短い呻き声 | groan |
| すすり泣き | sob |
| 悲鳴 | scream |

許可リストは読点又はカンマ区切り。表の日本語名又はコードを使用する。自由文の発声説明を実行eventへ直接流さず、この閉じた語彙から選ぶ。未知の種類・パターンはエラーにする。

## Scene EMDとH3

非言語発声はShot内の`NONVERBAL`で保存する。typed artifactでは既存eventと同じ時刻・人物fieldを持つ`kind=vocal`、`dialogue_id=null`、`language=null`とする。textは許可された種類コードのみ。発声は参加人物に限定し、小物・environmentを話者にしない。同じ人物の台詞と非言語発声、又は非言語発声同士の時間重複は拒否する。

```text
* NONVERBAL scene_gasp 00:01.000 --> 00:01.500 | @hero | gasp
* DIALOGUE dlg_home 00:02.000 --> 00:04.000 | @hero | 「ただいま。」
```

Compilerは固定の英語指示と発声強度に変換し、台詞の外へ出力する。非言語発声を翻訳モデルへ渡して新しい言葉に変換しない。

```text
[00:01.000 --> 00:01.500] NONVERBAL <Subject 1>: gasps briefly, quietly. Nonverbal sound only; no spoken words.
[00:02.000 --> 00:04.000] <Subject 1> speaks <d>[Japanese]ただいま。</d>
```

実際のH3向け時刻は既存の24fps格子へ補正する。`NONVERBAL`はVCのイベント表現であり、H3固有タグではない。声質参照は非言語発声だけの人物にも有効化する。画面外人物の画像・動画は有効化しない。EFFECT/AMBIENCEへの発声の迂回は引き続き禁止する。

パターン定義と確定設定・eventはScene EMDへ保存し、再読込・再コンパイルで保持する。saved_sceneモードは新しい声を自動計画しない。追加するにはscenarioモードでBuildを再実行する。既存WFのノードやwidgetの追加は不要。

### 計画時の時間重複の部分修正

`NONVERBAL_OVERLAP`では、Scene全体を再生成する前に非言語発声の`start_ms`・`end_ms`だけを修正する。作者の台詞は本文・人物・言語・時刻を固定する。非言語発声もID・種類・人物・件数を保持し、元のShot内で台詞と重ならない時間枠を使う。元の動作と時刻・長さを優先し、空き区間へ収める必要がある場合だけ非言語発声を短縮する。長くしたり、イベントを削除して検証を回避したりしない。

固定長tupleとID定数の生成Schema、Pythonの時間重複・24fps格子・音のtrigger検証を併用する。一Sceneにつき部分修正は一セッション・最大二応答で、三回目の全体生成後でも実行できる。修正後は全体検証を必須とし、成功したSceneだけをキャッシュする。空き時間がない場合は、人物・発声ID・Shot区間・固定台詞のIDと区間を日本語で示す。既存のsaved_sceneを読み込む処理は自動修正せず、従来どおり検証する。
